# 일단 Runpod에 올려봄

Runpod에서 궁금했던 것들을 직접 돌려보고, 코드와 시행착오를 함께 남깁니다.

가짜연구소 시즌 13에서 진행하는 12주 프로젝트입니다. Runpod을 사용하며 발견한 문제를 각자 작은 실험으로 풀어봅니다. 잘된 결과뿐 아니라 안 된 이유, 실제 비용과 운영상의 한계도 공유합니다.

## 어떻게 진행하나요?

각 실험은 약 2주 동안 진행합니다. 시작 시점을 한 주씩 겹치게 잡아 3주차부터 매주 결과를 공유합니다. 한 사람이 발표하는 동안 다음 사람은 실험을 진행하는 방식입니다.

| 주차 | 실험 A | 실험 B | 실험 C |
| --- | --- | --- | --- |
| 2주차 | 설계·구현 | | |
| 3주차 | 검증·발표 | 설계·구현 | |
| 4주차 | | 검증·발표 | 설계·구현 |
| 5주차 | | | 검증·발표 |

같은 주제를 여러 명이 맡아도 됩니다. 앞선 실험을 재현하거나 GPU, 모델, 프레임워크, 설정을 바꿔 비교하는 것도 좋습니다. 발표 순서와 실험 횟수는 참여 인원과 난이도에 맞춰 조율합니다.

자신의 차례가 아닐 때도 리뷰, 테스트와 질문으로 참여합니다. 발표는 현재까지 확인한 결과를 공유하는 자리이며, 모든 주제를 완성된 핸즈온 강의로 만들 필요는 없습니다.

## 어떤 실험을 하나요?

주제는 참여자가 가져온 문제를 바탕으로 정합니다. 예를 들면 다음과 같습니다.

- 모델 배포와 추론 최적화
- GPU·런타임·설정에 따른 비용과 성능 비교
- 파인튜닝 워크플로우
- Serverless의 콜드 스타트와 스케일링
- 이미지·영상·음성 생성 워크로드
- 스토리지, 데이터 전송과 체크포인트 운영

큰 주제 하나보다 **2주 안에 확인할 수 있는 질문 하나**로 시작합니다.

## 누구와 함께하나요?

- Runpod에서 모델이나 워크로드를 직접 실행해본 분
- 해결하거나 검증해보고 싶은 구체적인 문제가 있는 분
- Python, Git/GitHub, Linux와 Docker를 기본적으로 사용할 수 있는 분
- 12주 동안 모임과 실험에 참여하고, 다른 구성원에게 피드백을 줄 수 있는 분
- 코드와 실험 결과를 가능한 범위에서 공개할 수 있는 분

Runpod 사용법을 처음부터 배우는 입문 스터디는 아닙니다. 사용 기간보다 무엇을 해봤고 무엇을 확인하고 싶은지를 중요하게 봅니다.

## 자료는 어디에 남기나요?

```text
weekly/       # 매주 모인 내용, 결정사항, 다음 할 일
hands-on/     # 실험별 실행 방법과 코드
templates/    # 복사해서 쓰는 기록 양식
```

Discord에서 대화하고 이 레포에 기록과 실험 원본을 남깁니다. Notion에서는 정책과 전체 운영 일정을 관리합니다. 정리된 사례는 작성자와 공개 범위를 확인한 뒤 블로그와 Runpod Korea User Group에서도 소개합니다. 원본 링크와 기여자 이름을 함께 남깁니다.

본 프로젝트는 가짜연구소의 커뮤니티 프로젝트이며, Runpod의 공식 교육·인증 프로그램은 아닙니다.
