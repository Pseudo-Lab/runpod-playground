# 추가 실험 실행 기록과 계획 대비 차이

실행: 2026-10-24 11:03~11:30 KST. 분석·도표 검증은 자원을 삭제한 뒤 로컬에서 수행했다. 원래 실험 자료는 유지했다.

## 실제 실행 순서

1. 가격 캐시 만료를 확인해 갱신하고 현재 재고를 별도로 조회했다. RTX5090 EU-RO-1 $1.19/h를 상한으로 동결했다. L4 EU-RO-1 $0.59/h만 사용했고 생성마다 live quote와 응답 단가를 확인했다.
2. 최초 준비 Pod에서 의존성·모델을 준비했다. 비교 전 GPU 학습 코드의 seed99 사전 점검도 수행했다. 이 seed는 본 실험 표본에 포함하지 않았다.
3. 준비 작업은 성공했지만, 없는 선택적 `result.json`을 SFTP로 회수할 때 빈 로컬 파일이 남아 제어기가 JSON 파싱에 실패했다. 자원을 모두 삭제하고 원자료를 `records/followup/attempts/attempt01/`로 보존했다. 수정 전 코드도 기록된 패치의 역적용으로 복원했고 사전등록 SHA-256과 정확히 일치함을 검증했다.
4. SFTP ENOENT 때 생성된 빈 로컬 파일을 제거하도록 제어기만 수정했다. GPU workload와 실험군·임계값은 바꾸지 않았다. 다시 사전등록하고 새 전용 volume과 준비 Pod에서 시작했다. 원래 실패 비용은 후속 예산 예약과 최종 비용 합계에 포함했다.
5. 준비 Pod를 삭제한 뒤 새 Pod 3개에서 ABC / BCA / CAB 순서로 저장 위치 실험9개를 수행했다. 모델 hash·출력 토큰은 모두 일치했다.
6. 학습용 Pod에서 세 seed의 무중단120-step와73-step 중단을 수행했다. 최신 확정60-step checkpoint와 기준 최종 가중치는 S3 전체 객체로 내려받아 로컬에 보관했다. 개별 checkpoint는 약3.72MB다.
7. 해당 Pod를 삭제한 뒤 다른 ID의 Pod에서 F/W 각3개를 수행했다. F/W 최종 가중치6개도 별도 S3 회수 작업으로 내려받고 결과 JSON의 SHA-256과 대조했다. 해당 회수는 GPU 작업이 아니라 로컬에서의 읽기 작업이며 일부 복구 실행과 시간이 겹쳤다. 소형 원본은 `private/followup-backups/`에, 공개 증거는 두 backup manifest에 있다.
8. 마지막 Pod와 전용 network volume을 삭제하고 API로 계정 Pod0개·volume0개·현재 시간당 사용액0을 확인했다. 독립 watchdog이 종료될 때까지 기다렸다.

## 측정 범위와 생략 사항

- 저장 위치 실험의 주 시간은 staging 직전부터 결과 산출까지다. 부모 Python의 초기 표준 라이브러리 import·인자 파싱은 제외한다. 이 점은 설계의 '프로세스 시작'이라는 표현보다 좁다. wrapper 전체 수명과 로컬 왕복시간도 원자료에 보존했다.
- 학습 Pod에서 별도의 CPU 행렬곱 대조 smoke는 수행하지 않았다. GPU 학습 사전 점검, 유한 loss 검사, 무중단 대비 전체 파라미터·평가 loss·batch 경로 비교를 수행했다. 이 실험을 GPU 연산의 CPU 대비 수치 정확도 검증으로 해석하지 않는다.
- 새 Pod ID는 확인했지만 서로 다른 물리 호스트로 이동했는지는 검증하지 않았다. 복구 세 seed는 한 쌍의 전후 Pod를 공유한다.
- 최초 설치·다운로드는 비교 측정과 분리했고 비용에서는 제외하지 않았다. provider/OS 파일 캐시를 강제로 초기화하지 않았다.
- 가중치만 복구한 W는 평가 loss가 더 낮았다. W의 학습률·데이터 순서·RNG가 달라졌으므로 이것을 복구 재현 성공이나 특정 상태 하나의 효과로 주장하지 않았다.
- 혼합 정책, 실제 사용자 trace, 대형 LLM 학습, AMP·분산학습, multipart 중단 재개는 미실시다. 아이디어 목록에 있는 항목을 모두 실행한 것으로 읽으면 안 된다.

## 자료와 재현

`records/followup/preregistered.json`에는 실행 전 코드·선정 문서·4개 설계/계획 파일의 hash가 있다. 최종 분석 코드는 `scripts/summarize_followup.py`이며 도표는 Matplotlib3.11.2, NumPy2.4.6으로 생성했다. 추가 실행의 usage는 조회 당시7개 Pod 중0개만 반영됐으므로 확정 비용은 null이며 추정값을 사용했다. 기존 실험17개 Pod의 별도 사후 조회와 혼동하지 않는다.

제어기는 이미 존재하는 원장과 결과를 덮어쓰지 않도록 멈춘다. 재실행하려면 별도 실험 복사본에서 기존 `records/followup/`와 비공개 원장을 보존·분리하고, 최신 가격·재고·계정 상태의 사전점검을 다시 생성해야 한다. 기존 실행 결과를 지우고 같은 실행인 것처럼 덮어쓰지 않는다. `.env`·SSH 비밀키·학습 가중치 원본은 Git에서 제외한다.
