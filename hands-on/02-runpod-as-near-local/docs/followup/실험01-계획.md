# 실험 01 실행 계획

발표일 2026-10-27 전에 2026-10-24 실행·분석을 목표로 한다. 문서만 작성하고 중단하지 않고 실제 유료 실행까지 수행한다.

1. 읽기 전용 사전점검으로 기존 Pod/volume, 잔액, 최신 가격과 S3 지역 재고를 조회한다. 가격은 기존 로컬 TTL 캐시를 재사용하고 만료 시 갱신한다. 이번 RTX 5090 견적을 상한으로 동결한다. 현재 사전점검은 L4 EU-RO-1 $0.59/h, 5090 상한 $1.19/h다.
2. 추가 실험 전용 원장 `private/followup-ledger.json`과 독립 watchdog을 시작한다. 기존 실험 원장·결과를 수정하지 않는다. 전체 추가비용 예약 한도 $8(저장소 여유 포함), 전체 4시간 만료, Pod 최대 수명 35분, 동시 Pod 최대 1개다. 기존 실험 지출 약 $0.45를 포함해 원래 $20보다 충분히 낮게 제한한다.
3. 전용 network volume 20GB를 생성한다. 새 Pod 1개에서 모델·의존성만 공통 준비하고 다운로드·설치시간을 기록한다. 모델 hash는 기존 manifest와 대조한다. 이 준비 실행은 비교 표본이 아니다.
4. 준비 Pod를 첫 블록으로 재사용할 경우 해당 사실을 기록한다. 이 경우 나머지 2블록만 새 Pod가 되므로 계획의 '새 Pod 3개' 조건을 충족시키기 위해 **준비 Pod는 삭제하고 블록용 Pod 3개를 별도로 생성한다**.
5. 블록 1 ABC, 2 BCA, 3 CAB를 순차 실행한다. 각 측정 최대 8분, 블록 전체 최대 30분. 원격 프로세스는 분리 실행하며 SSH 끊김이 무한 유지로 이어지지 않도록 만료 정리한다.
6. 매 블록 결과 JSON·로그를 로컬로 회수하고 manifest hash를 확인한 다음 Pod 삭제와 API 부재를 확인한다. 재고 실패는 무한 재시도하지 않고 최대 3회까지 기록한다.
7. 실험 02에 필요한 공통 volume을 넘긴다. 모든 결과 회수 후 전체 volume까지 삭제한다. 별도 S3 저장소를 남기지 않는다.

예상: 공통 준비 5~15분, 3블록 15~45분, 실패 여유 20분. 일반 예상 지출 $1~2지만 실제 완료시간·단가는 측정하고 공급자 확정 청구와 구분한다. 부가비용 추정은 20GB volume $0.07/GB/월, container disk $0.1/GB/월을 720시간으로 환산하고 현재 문서와 대조한다.

산출물: 동결 설정과 소스 hash, 블록별 환경·원자료, 시간 분해 그래프, 비교 표, 실패 기록, 비용 추정·청구 상태·정리 확인. `python scripts/followup.py`가 실행 제어기이며 결과가 존재하는 실행을 덮어쓰지 않는다.
